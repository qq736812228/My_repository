# Changelog

## 1.0.0

- 统一后端包名为 `com.obai.platform`。
- 交付 Spring Boot 后端、Vue3 管理端、uni-app 小程序三端工程。
- 完成 PostgreSQL SQL、基础数据、RBAC、操作日志、报表、商城、检测、档案、自测、积分、邀请、商户发布等闭环。
- 补充 Docker、环境隔离、接口联调、数据库关系、小程序按钮映射文档。

## 1.1.0

- 修复 Spring Data JPA 派生查询字段错误。
- 后台 `/api/admin/**` 增加 ADMIN 角色校验。
- 管理端 CRUD 改为显式 Schema 表单，支持空表新增和局部字段更新。
- 后端 PUT 更新引入非空补丁式实体复制，避免覆盖关系字段和审计字段。
- 微信登录接入 `jscode2session`，开发环境保留可配置兜底。
- 微信支付增加 JSAPI 预下单请求签名、前端支付参数签名和支付回调订单状态同步。
- 补充字典、行政区、订单明细、支付回调、AI 报告等后台入口与文档。
